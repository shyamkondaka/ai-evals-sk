## Method + Ground Truth (two ✅/⚠️ cells)

### Hallucination Rate
- **Method:** Automated fact-verification pipeline that chunks each generated summary into individual claims, then cross-references each claim back against the source research report using a retrieval-based consistency checker
- **Ground truth:** The source confidential research report itself — specifically the verbatim passages, cited statistics, named entities, and directional conclusions contained within it. A claim in the summary is evaluated as grounded if a retrieval match above a defined similarity threshold exists in the source document, and flagged as a potential hallucination if no such match is found.

### Latency
- **Method:** Method:
Standard APM (Application Performance Monitoring) tooling tracks p95 response times and end-to-end pipeline duration from report ingestion to client delivery, with automated alerts triggering when delivery SLAs are missed or when generation time exceeds a defined threshold on a rolling window.
- **Ground truth:** The contractually committed client delivery SLA — the agreed turnaround time between report submission and summary delivery to the client's inbox or web portal — which serves as the fixed benchmark against which every pipeline run is measured, making this the one risk where the ground truth is defined by the business contract rather than the source document.

## Strategic acceptance

**Accepted gap:** Toxicity (UX Trust)

The input is confidential research reports and the output is professional executive summaries — the content domain makes toxic output extremely unlikely. This does not mean zero coverage, but it is the lowest priority and the easiest to defend at L1

## Critical mitigation

**Critical gap:** Drift Monitoring (Robustness)

**Why critical:** Drift Monitoring is a critical gap that needs a dated mitigation plan — it will surface as a real incident eventually

**Mitigation plan:** Establish a locked golden summary baseline library of 20–30 human-reviewed outputs across all major report types within the first three weeks, then instrument the production pipeline to automatically track factual grounding scores, semantic similarity, and coverage distribution against those baselines
